## 二、核心科研四问（无过度承诺，负结果同样高含金量）

1. **Q1（切分阶梯与位点记忆）**：已测过同一位点的其他替换，给预测带来了多少便利？在 10 蛋白 × 三切分上实测 `Site-Mean`、实际测试位点已见率、最近训练位点 1D 距离与各方法成绩衰减。
2. **Q2（核心主战：相同总标签预算下 LoRA vs 冻结 Ridge）**：在 10 蛋白统一总预算 $N_{\text{total}} = 256$（`192 训练 + 64 验证`）下，预先锁定 **Contiguous 上的配对差 $\Delta\rho = \rho_{\text{LoRA}} - \rho_{\text{Ridge}}$** 为核心检验量；在 3 个蛋白上做 $N_{\text{total}} \in \{64, 256, 1024\}$ 学习曲线与换种抽样稳健性检验（并可选加 1 组 96 条“广度散测 vs 深度集中测”湿实验策略对比）。
3. **Q3（真实酶工程筛选与三维机制解释）**：在 **`OXDA_RHOTO`（DAOx）** 上，更高的 Spearman 能否转化为更高的回顾性候选筛选命中（折内固定 `Precision@10` / `EF@10%`）？同时区分“找对位点”与“选对替换（**位点内 Spearman**）”，结合 `1C0P` 结构壳层（FAD 域、`Y222/Y237/R284` 底物口袋、<5 Å / 5–10 Å / >10 Å）及同源 `expression` 表达表（6,769 条，注意标注共同变体数）剖析 1 个成功案例 + 1 个失败案例。
4. **Q4（探索扩展：监督读出能否改变 650M 与 3B 的相对排序？）**：在预先锁定的 5 蛋白上，先用相同 masked-marginal 诊断 650M vs 3B 野生型原始对数概率分布（绝不四舍五入造假饱和），对比 $D_0 = \rho_{\text{3B,ZS}} - \rho_{\text{650M,ZS}}$ 与 $D_R = \rho_{\text{3B,Ridge}} - \rho_{\text{650M,Ridge}}$；资源达标后再跑 25 次 Contiguous `3B-LoRA` 探索（逐蛋白展示，允许全部不反转）。

## 四、零漏洞实验协议：三切分、嵌套防泄露、对照基线与统计口径

### 4.1 严格防泄露规则（6 条铁律）
1. **外层五折只读官方列**：按 `DMS_id + mutant` 严格对齐，同一蛋白、同一切分、所有方法与所有 $N$ 共享完全相同的测试变体；核验零样本在相同测试折下分数完全不随 $N$ 变动。
2. **内层验证复用同策略的另一个官方折**：外层测试折为 $k$，固定用 $(k+1)\bmod 5$ 作验证池，其余 3 折作训练池。`Modulo` 和 `Contiguous` 下代码断言 `train_pos`、`val_pos`、`test_pos` **两两交集为空**。（答辩诚实表述为**“外层五折、内层预定单一留出折”**，不虚称为内层完整五折。）
3. **总标签预算含验证（杜绝 REAP 式的隐性加倍标签）**：
   * $N_{\text{total}} = 64 \rightarrow 48\text{ 训练} + 16\text{ 验证}$；
   * $N_{\text{total}} = 256 \rightarrow 192\text{ 训练} + 64\text{ 验证}$；
   * $N_{\text{total}} = 1024 \rightarrow 768\text{ 训练} + 256\text{ 验证}$。
   * 较小预算严格取较大预算固定随机序的**前缀**；每次保存 `n_train / n_val / 覆盖独立位点数 P_unique / 测试已见位点比例 / 最近训练位点 1D 距离`。早停后保留所得模型，主分析不再并入验证集重训以保持拟合次数与预算口径完全一致。
4. **超参、标准化与开发蛋白隔离**：Ridge 的 $\alpha$、特征与标签标准化全限训练侧；LoRA 的 lr / rank / 目标层 / 最大轮数仅在**面板外试跑蛋白**上一次性定死，正式阶段仅靠内层验证早停。
5. **明确“未见”的科学边界**：隔离的是该测定的**实验标签位点**（模型仍读取完整野生型序列，且预训练可能见过同源蛋白），绝不宣称“跨全新酶家族零样本迁移”。
6. **冻结特征缓存可复用，监督状态逐折彻底清空**：每折从零初始化预测头、优化器与 adapter，严禁把上一折 adapter 接着训下一折。

### 4.2 完整对照体系（5+1 阶梯 + 1 项低成本归因核验）

| 组别 | 固定实现与核心特征 | 回答的问题与实现铁律 |
| :--- | :--- | :--- |

### 4.3 统计检验、筛选指标与 6 条自动化单测门禁
* **跨蛋白主统计（严禁把 50 个折当 50 个独立蛋白！）**：先逐折算指标，再在蛋白内平均 5 折；主图画 10 蛋白各自的 `LoRA − Ridge` 配对差、中位差、正负方向数及逐个去掉一个蛋白（Leave-One-Protein-Out）敏感性图；单蛋白 95% CI 用**折内分层位点块自助法（Block Bootstrap, $B=2000$）**；严禁对 5 折做配对 Wilcoxon。
* **DAOx 筛选指标（免疫负值 Bug 与并列顺序作弊）**：
  * 固定每折预算 **`Precision@10`**（前 10 预测命中折内真实前 10% 精英的个数/比例 + 精确理论随机期望 + 富集倍数 `EF`，使用**精确并列期望公式**；图注明“五折分别各挑 10 个”，绝不合并成全库挑 50 个）；
  * 若原文对照支持野生型阈值，单列“超过 WT 命中数”，绝不拿中位数二值列冒充优于 WT；
  * **加报 DAOx 位点内 Spearman**（仅纳入含足够观测替换且标签有变异的位点并标清纳入数），区分“找对易损位点”与“选对最佳氨基酸替换”。
* **6 条必过 `pytest` 自动化防泄露门禁**（全绿方准开跑主实验）：位点三集两两不交断言、零样本随 $N$ 不变断言、`<cls>` 索引对齐断言、Hsu 未见位点退化断言、并列期望与行序无关断言、任务清单完整性与缺折显式标缺校验。
